Crypto RSA Easy

RSA Weak Keys

📅 December 2024 | 🏆 Example CTF 2024 | 💯 100 points

Challenge Description

"We've encrypted our secret message using RSA. The public key is strong... right?"

We're given a public key file and an encrypted message. Our goal is to decrypt the message and recover the flag.

Given Files

We received two files:

  • public_key.pem - The RSA public key
  • ciphertext.txt - The encrypted flag (base64 encoded)

Analysis

Extracting the Public Key Parameters

First, let's extract n and e from the public key:

from Crypto.PublicKey import RSA

with open('public_key.pem', 'r') as f:
    key = RSA.import_key(f.read())

n = key.n
e = key.e

print(f"n = {n}")
print(f"e = {e}")
print(f"n bit length: {n.bit_length()}")

Output:

n = 64064959164923876064874945473407049985543119992992738119252749003041961...
e = 65537
n bit length: 512

Interesting! The modulus n is only 512 bits, which is considered weak by modern standards. RSA keys should be at least 2048 bits for security.

Factoring the Modulus

A 512-bit RSA modulus can be factored using online databases or dedicated factoring tools. Let's check FactorDB: 

import requests

response = requests.get(f"http://factordb.com/api?query={n}")
data = response.json()
print(data)

The modulus was already factored in the database! We got our prime factors p and q.

Recovering the Private Key

With p and q, we can compute the private exponent d:

from Crypto.Util.number import inverse

p = 7991432856706713407  # Factor 1
q = 8017138972485278083  # Factor 2

# Verify
assert p * q == n

# Calculate phi(n)
phi = (p - 1) * (q - 1)

# Calculate private exponent d
d = inverse(e, phi)

print(f"d = {d}")

Decrypting the Flag

from Crypto.Util.number import long_to_bytes
import base64

# Read ciphertext
with open('ciphertext.txt', 'r') as f:
    ciphertext = base64.b64decode(f.read())

# Convert to integer
c = int.from_bytes(ciphertext, 'big')

# Decrypt: m = c^d mod n
m = pow(c, d, n)

# Convert to bytes
plaintext = long_to_bytes(m)
print(f"Flag: {plaintext.decode()}")

Complete Solution Script

from Crypto.PublicKey import RSA
from Crypto.Util.number import inverse, long_to_bytes
import base64

# Load public key
with open('public_key.pem', 'r') as f:
    key = RSA.import_key(f.read())

n, e = key.n, key.e

# Known factors (from FactorDB)
p = 7991432856706713407
q = 8017138972485278083

# Calculate private key
phi = (p - 1) * (q - 1)
d = inverse(e, phi)

# Load and decrypt ciphertext
with open('ciphertext.txt', 'r') as f:
    c = int.from_bytes(base64.b64decode(f.read()), 'big')

m = pow(c, d, n)
flag = long_to_bytes(m).decode()

print(f"Flag: {flag}")

Lessons Learned

  • RSA key size matters - always use at least 2048 bits
  • FactorDB is an invaluable resource for CTF crypto challenges
  • Understanding RSA mathematics is essential for crypto challenges
  • Small keys can be factored quickly with modern tools
